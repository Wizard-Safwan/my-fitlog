# FitLog

### Workout Library & Fitness Planner

FitLog is a dark, no-nonsense workout library and fitness planner built for people who want to discover workouts, build a daily plan, and keep track of completed exercises.


## 🛠️ Technologies Used

- **Next.js** 
- **React** 
- **TypeScript** 
- **Tailwind CSS** 
- **DaisyUI** 
- **React Icons** 
- **React Toastify** 

## ✨ Key Features

- Browse workout library
- Save workouts for later
- Mark workouts as done
- Sort workouts by duration, calories, or rating
- Save plan and workout data using local storage
- View detailed workout information
- Add workouts to today's plan
- Responsive design for mobile, tablet, and desktop

## 📱 Responsive Design

FitLog works responsive on:

- Mobile
- Tablet
- Desktop
